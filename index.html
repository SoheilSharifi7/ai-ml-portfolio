Portfolio Artifact 01: Machine Learning Algorithm Atlas

Introduction: Machine learning methods differ in their learning objectives, data requirements, and suitable tasks. This visual guide connects common algorithms to four application domains: tabular data, computer vision, NLP, and generative AI.

Description: A two-page, 12-method visual reference showing each method’s training approach, primary domain, how it works, and an illustrative real-world use case.

Objective: Compare algorithm families and communicate when they are useful in applied AI work.

Process: Selected representative methods across predictive, exploratory, language, vision, and generative tasks; distinguished learning paradigms from application domains; drafted concise descriptions and transportation-oriented examples; organized the results into a consistent visual layout.

Tools and technologies: Python, ReportLab, HTML/CSS, and AI-assisted drafting and editing.

Unique value: Translates abstract algorithm categories into decision-relevant examples from transportation and public-sector analytics.

Relevance: Helps students, analysts, and planning professionals identify candidate model families before deeper evaluation.

Explore the 12 Methods

Supervised · Tabular

Linear Regression

Fits a linear relationship to predict continuous values.

Use case: Forecast daily transit boardings.

Supervised · Tabular

Decision Tree

Splits records using feature-based decision rules.

Use case: Classify transit stops by performance.

Supervised · Tabular

Random Forest

Aggregates predictions from many randomized trees.

Use case: Predict paratransit trip demand.

Supervised · Tabular

Gradient Boosting

Adds models sequentially to correct prior errors.

Use case: Estimate corridor travel times.

Supervised · Tabular / NLP

Support Vector Machine

Finds a margin-maximizing classification boundary.

Use case: Classify service requests.

Unsupervised · Tabular

K-means

Groups similar observations around cluster centers.

Use case: Segment transit rider patterns.

Unsupervised · Tabular / Vision

PCA

Projects features onto directions of maximum variance.

Use case: Summarize correlated accessibility indicators.

Usually supervised · Computer vision

CNN

Uses learned filters to extract spatial image patterns.

Use case: Detect bus stops in street imagery.

Self-supervised + fine-tuned · NLP

BERT

Learns bidirectional text representations with attention.

Use case: Classify public comments by topic.

Self-supervised + aligned · NLP / Generative AI

GPT / autoregressive transformer

Predicts the next token to generate coherent text.

Use case: Draft summaries of planning documents.

Adversarial generative · Generative AI / Vision

GAN

Trains a generator against a discriminator.

Use case: Create synthetic training imagery.

Generative denoising · Generative AI / Vision

Diffusion model

Learns to reverse noise to synthesize samples.

Use case: Generate concept illustrations.
